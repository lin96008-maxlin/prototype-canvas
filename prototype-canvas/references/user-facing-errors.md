# 用户可见异常提示

localhost 和独立画布的异常提示面向不懂代码的产品经理。界面只说明“发生了什么”和“下一步怎么做”；技术原文可写入浏览器控制台，不能直接显示 Token、Selector、Manifest、Hash、HTTP 状态或本机路径。

| 异常场景 | 用户看到的提示 | 用户处理 |
| --- | --- | --- |
| 本地服务重启，旧页面凭证失效 | 本地编辑服务已经重启，当前页面已失效。请刷新浏览器页面后再试。 | 刷新当前页面 |
| localhost 已停止或网络连接失败 | 无法连接本地编辑服务。请确认 localhost 仍在运行，然后刷新页面重试。 | 重启服务并刷新 |
| 编辑会话已应用、结束或不匹配 | 当前编辑会话已经结束。请重新打开本地编辑地址后再操作。 | 重新运行 `serve` |
| 原型 HTML 在编辑期间发生变化 | 原型文件已经发生变化，当前画布不能继续保存。请重新分析原型后再编辑。 | 重新执行分析与编辑 |
| 画布数据不完整或结构校验失败 | 画布数据不完整，暂时无法保存。请撤销最近一次操作；如果仍未恢复，请刷新页面。 | 撤销或刷新 |
| 保存内容超过本地服务限制 | 本次保存的数据量过大，浏览器无法提交。请减少一次操作的内容后重试。 | 减少单次内容 |
| 请求内容损坏或格式不完整 | 本次请求内容不完整。请刷新页面后重新操作。 | 刷新后重试 |
| 节点已被删除或不存在 | 这个节点已经不存在。请刷新页面后重新选择节点。 | 刷新并重选 |
| 节点尚未关联页面 | 这个节点还没有关联原型页面，请先点击“重新定位”完成关联。 | 完成页面关联 |
| 找不到回放所需的点击入口 | 没有在原型中找到需要点击的入口。页面可能尚未加载完成，或原型结构已经变化，请重新定位这个节点。 | 重新定位 |
| 找不到之前关联的目标页面 | 没有找到之前关联的页面。原型内容可能已经变化，请重新定位这个节点。 | 重新定位 |
| 原型加载或定位超时 | 原型页面加载时间过长。请稍后重试；如果仍然失败，请重新打开本地预览。 | 重试或重启预览 |
| 回放内核未加载 | 原型页面加载时间过长。请稍后重试；如果仍然失败，请重新打开本地预览。 | 重试或重启预览 |
| 页面已定位但快照生成失败 | 页面已经定位，但预览图片没有生成成功。请稍后重新关联。 | 稍后重新关联 |
| 本机没有可用的 Chrome 或 Edge | 电脑上没有找到可用的 Chrome 或 Edge，暂时不能生成页面预览。 | 安装或启用浏览器 |
| 预览采集服务已经关闭 | 本地预览服务已经停止。请重新启动 localhost 后再试。 | 重启服务 |
| 当前画布没有可导出节点 | 当前画布没有可导出的节点。 | 新增节点后导出 |
| 导出内容校验失败 | 导出内容校验失败，请重试。 | 重新导出 |
| 画布超出浏览器位图能力 | 画布尺寸超出浏览器限制，请改用 SVG 导出。 | 改用 SVG |
| 未分类的本地服务错误 | 本地编辑服务处理失败。请刷新页面后重试；如果仍然失败，请重新启动 localhost。 | 刷新或重启服务 |

关联确认期间显示全屏蒙层，阶段依次为“正在确认页面关联”和“验证完成，正在保存”。成功后自动返回画布；失败时关闭蒙层、保留原关联，并用居中对话框显示上述提示。
