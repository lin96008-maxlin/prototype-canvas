# 工作流

## 生成

1. 校验输入是可读取的单个 `.html` 文件，计算 SHA-256。
2. 静态分析显式 `data-proto-*` / `data-zann-*` 契约、常见页面容器、导航、Tab、Dialog 和身份控件。
3. 生成草稿 Manifest 与置信度报告。每个原型先建立未绑定的系统起点，再按一级导航、二级导航、后续导航、页面、页面操作 / 状态 / 下钻交互形成 `hierarchy`；显式契约优先，启发式结果必须保留证据。
4. AI 结合源码、真实运行结果和用户材料复核草稿。状态型 Tab 有独立操作或下钻关系时保留；纯展示 Tab 不建节点。允许页面、导航、情形和空白节点形成独立树；弹窗、抽屉、Tab、步骤和页面状态必须根据真实操作轨迹归入触发页面或上级下钻交互。
   - 复核通过 `review` 输出的精简复核包进行，不直接读取整个 Manifest：复核包按业务身份去重，同一业务页面在所有业务空间中的副本只占一条，说明只写一次，再用 `describe` 批量写回全部副本。
   - `describe` 返回的 `unknown` 必须逐条处理，不得忽略；写回同时清除已解决的 `analysis.unresolved`。
   - 复核前先做结构探查：`probe` 在每个全新页面里逐个点击真实入口，按实际结果区分页面容器、浮层、仅状态变化和无效入口，用来纠正静态分析猜错的层级与入口。默认最多 48 个入口、3 分钟预算、并行 3 路，先展开默认收起的导航分组再枚举，单个入口失败不影响其他入口。
   - 探查结果与静态草稿冲突时以探查结果为准。确认后的关联用 `bind` 一次写回全部画布副本：已有用户手动定位的关联默认不覆盖（`--force` 才覆盖），关联变化会作废该节点的旧预览，采集阶段必须重新生成。
   - 探查只覆盖"从初始状态可达"的入口；两步以上才能到达的页面需要在探查结果基础上继续补充，不得把未探查到的路径当成已验证。
5. 发布前执行 `verify` 关联体检：每个已关联节点都从整页初始状态重放一次，只报告能否到达目标，失败即退出码 3，必须先修好再继续。体检不生成截图，整轮体检量与采集相当。
6. 逐节点、逐有效用户类型捕获可达快照；相同视觉结果按 Hash 去重。已关联节点没有 `ready` 快照时回到定位步骤修复，不能继续发布。
   - 采集默认并行 3 路（`--concurrency` 可调，设为 1 即回到串行）。每个并行通道使用相互隔离的浏览器上下文，节点之间不得共享页面状态。
   - 同一通道内只有上一次采集留下了可见浮层时才重新整页加载；否则复用当前页面继续采集，回放失败时自动整页重载并重试一次，失败结果不计入成功。
   - 采集过程向标准错误输出进度（完成数量与最终耗时）；`PROTOTYPE_CANVAS_PROGRESS=0` 可关闭。时间预算优先用于减少整页重载次数，不得用降低等待时间的方式换取速度。
7. 生成画布 HTML。源原型以 Base64 形式只内嵌一次，运行时只创建一个可复用 iframe。
8. 执行审计和浏览器检查，失败时说明原因和修复方向，不把空白画布当成成功。

## 更新

- 源 HTML 未变：复用稳定 Node ID、人工页面说明、用户类型和双模式位置，只刷新需要更新的识别项与快照。
- 源 HTML 已变：生成新草稿并按稳定 Scope / Selector 迁移人工内容；不能匹配的内容进入待确认，不静默丢弃。
- 输出永远是新文件；文件名前缀固定为 `20260901-（画布）`，同名时使用 `-v2`、`-v3` 递增。

## 编辑

- 每次 `serve` 创建或恢复一个独立 Session，服务只监听 `127.0.0.1`，编辑 API 必须携带随机 Token。
- 标题、节点、联系线、树归属 / 顺序、根节点位置、用户类型树、页面说明和按用户类型保存的关联定位均写入 Session。
- 根节点拖动整棵子树，也允许吸附为其他节点的子树；非根节点拖动用于换父级、同级排序或脱离为独立树。拖拽过程中只移动节点预览并显示目标占位，层级线和联系线在松手提交前保持原位。同级节点固定纵向排列，跨节点连线不参与层级排版。
- 框选后的多个节点按“最上层已选子树”整组拖动，不能重复移动已随父节点选中的后代；结构变更后自动分离重叠的独立树。
- 画布命令使用命令栈实现撤销重做；标题或富文本聚焦时使用浏览器编辑历史。
- Delete / Backspace 直接删除所选节点的整棵子树或所选联系，并允许撤销；层级线不能单独选中或删除。关联定位确认前不写入正式 Manifest。
- `apply` 前校验源 Hash、Manifest 基线和 Session；冲突即停止。

## 页面说明

- 字段固定为页面名称、节点类型、页面说明。用户类型由当前独立画布决定，不在单个节点内重复设置。
- AI 初始化只描述原型可见内容及已确认材料，不补造规则。说明使用产品语言回答“谁在什么场景使用、解决什么问题、主要查看或处理什么、操作产生什么结果”；证据、Selector、JavaScript 模块名和置信度只进入技术字段。
- 静态分析生成的说明只是草稿。AI 必须逐节点复核、写回 `descriptionSource: "ai-reviewed"`；用户在编辑器修改后写回 `descriptionSource: "user"`。最终发布拒绝技术模板、占位文案和过短说明。
- 页面说明存储安全 HTML，不存 Markdown。允许段落、标题、粗体、斜体、下划线、列表、引用和链接。

## 快照与高清预览

- 默认节点显示压缩快照；Web 缩略图默认限制为 720px 宽，满足 360px 节点的 2 倍像素密度，移动端保留原型基准宽度；非首屏图片延迟解码。
- 画布达到进入阈值后，自动选择距视口中心最近且占据足够可见面积的节点，把唯一共享 iframe 移到其快照区；无需先选中。
- 是否进入高清预览按节点在屏幕中的实际显示宽度判断，不绑定固定缩放百分比；进入与退出使用不同阈值，避免反复切换。平移及阈值内的小幅缩放只更新容器位置，不重建或重新导航 iframe。
- iframe 在节点内始终 `pointer-events: none`。双击同一节点进入原型模式时直接复用已完成回放的 iframe 并启用交互；目标节点或用户类型变化时才重新加载。
- 新目标未就绪前保留旧快照；超时或异常回退快照。
- 人工关联提交后立即显示“正在渲染”反馈，由 localhost 服务只重采当前节点；成功后原位替换为快照，失败时保留可理解的失败状态。定位桥接未就绪或没有有效目标时禁止确认。

## 完成标准

- 输出命名、自包含审计、Manifest 结构、节点数量和源 Hash 正确。
- 两种画布分别保存位置、尺寸、锁定状态和视口。
- 单击、双击、拖动、快捷键和编辑器焦点无冲突。
- 用户类型管理以大弹窗呈现，可查看、搜索、缩放、框选、拖拽、增删改、折叠、通过鸟瞰图定位及切换；节点只编辑名称、预设类型和说明，不提供联系、页面关联或节点业务详情。一级画布负责页面节点和页面关联。
- 鸟瞰图有独立倍率且不改变主画布倍率，内容超限时有横向和纵向滚动条，拖动视口框时持续同步主画布。
- 鸟瞰图内部滚轮只滚动自己的滚动条：普通滚轮纵向、`Shift + 滚轮` 横向，不修改主画布视口。
- 主画布、用户类型画布及两者的鸟瞰图均受真实内容范围约束，不能把导图完全移出可见区域。
- 导出入口只保留完整思维导图 SVG 与完整页面快照 SVG；两类 SVG 都包含对应骨架图例，快照模式内嵌当前已有原型快照。
- 验证 HTML 均能生成非空画布并打开至少一个页面目标；若某用户类型确实没有任何节点，则显示空画布状态而不是伪造首页。
